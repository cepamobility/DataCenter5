EVENTOS
 
A função Eventos se desdobra da seguinte forma.

 
Evento/Gerenciamento
 
 
 
Este item permite ingressar, editar e excluir os dados de acidentes/incidentes e multas no Data Center. Todos os campos sinalizados com * devem ser compulsoriamente preenchidos.
  • Para ingressar um acidente ou incidente clicar sobre a opção Novo Acidente/ Incidente.
  • Para ingressar uma multa clicar sobre a opção Nova Multa.

      Forneça o máximo de informação possível. Recomendamos a realização de uma busca simples ou avançada antes do ingresso visando assegurar-se que o evento já não tenha sido ingressado.

  • Para editar um evento uma busca simples ou avançada deve ser efetuada. Ao encontrar o evento desejado clique na data e os detalhes do mesmo serão exibidos. Clique na opção Editar e ingresse as alterações desejadas, depois clique em "Salvar".
  • Para excluir um evento siga o mesmo processo de busca do item anterior, mas ao serem exibidos os detalhes do evento clique na opção "Deletar".
