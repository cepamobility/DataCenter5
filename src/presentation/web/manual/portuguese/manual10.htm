Frotas/Ingresso Km/Milhas e Eventos Coletivos
 
Nesta tela é possível selecionar a frota para a qual o usuário irá ingressar os dados coletivos ou individuais de quilometragem/milhagem percorrida em um determinado período. Para isso basta utilizar a busca.
Esta utilidade pode substituir os dados enviados mensalmente ao CEPA Data Center.
Aqui também é possível ingressar os eventos reportados de forma coletiva (eventos não reportados por formulários).

Descrição do processo operacional para ingresso de forma coletiva:

  • Selecionar o nome da frota (através da busca);
  • Selecionar o período para o qual o usuário irá informar os dados;
  • Clicar no nome da frota;
  • Para cada Divisão informar o número de veículos, milhas/quilômetros percorridos, acidentes e incidentes ocorridos no período informado e clicar em "Salvar".

Descrição do processo para ingressar eventos coletivos: Na mesma tela de ingresso de km/milhas coletivas completar os campos que correspondem aos dados de acidentes e incidentes: Divisão, Classificação, Quantidade, etc.

Descrição do processo operacional para ingresso de forma individual:

  • Selecionar o nome da frota (através da busca);
  • Selecionar o período para o qual o usuário irá informar os dados;
  • Clicar no nome da frota;
  • Informar a leitura atual do odômetro, quantidade de acidentes e incidentes para cada veículo.
