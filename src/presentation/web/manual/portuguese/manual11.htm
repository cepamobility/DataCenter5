INSTRUÇÕES BÁSICAS DE ACESSO E USO
Frotas/Consultas/Veículos 
 
 
Este item fornece uma lista dos veículos que cumprem as características estabelecidas pelo usuário. É possível buscar veículos por marca, tipo, centro de custo, divisões, etc. Após selecionar os critérios de definição do veículo o Data Center exibirá uma relação contendo dados simples ou detalhados, de acordo com os itens selecionados na tela de busca. Por exemplo, na busca detalhada serão exibidos dados como: região/país, divisão, subdivisão, centro de custo, tipo do veículo, uso, marca, modelo, ano de fabricação, combustível, placa, condutor, etc.
Esta tela mostrará adicionalmente o número total de veículos que cumprem os critérios estabelecidos.

 
Frotas/Consultas/Km/Milhas por Divisão
 
 

Após selecionar os critérios de definição da frota como período, divisões, unidades, etc. o Data Center exibirá um quadro com os seguintes dados: região/país, unidade, divisão, subdivisão, veículo designado, número de veículos, milhas/quilômetros, número de acidentes, APMM, número de incidentes, IPMM, % de veículos em acidente, além de totais e subtotais.
