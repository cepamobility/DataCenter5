Frotas/Gerenciamento de Veículos
 
Este item permite registrar, modificar e excluir veículos da mesma forma que o item Condutores (Gerenciamento).
  • Para Adicionar um veículo clique em "Adicionar Veículo". Todos os campos marcados com * devem ser compulsoriamente preenchidos. A inclusão do veículo passará à supervisão e a equipe CEPA ficará encarregada de realizar as possíveis correções bem como solicitar mais informações, conforme necessário.
  • Para Excluir um veículo será necessário primeiro executar uma busca simples ou avançada, estipulando características específicas para o veículo. Uma lista com todos os veículos que cumprem os critérios selecionados será então exibida. O usuário deverá selecionar o veículo a ser excluído e na próxima tela clicar na opção "Desativar". Preencher os campos data da exclusão e comentários (motivo da exclusão) e clicar no botão "Desativar". Este veículo não estará mais ativo para pesquisas ou buscas, porém os dados registrados (milhagem/ quilometragem, eventos, etc.) não serão excluídos.
  • Para Alterar os dados de um veículo será necessário primeiro realizar uma busca onde serão estabelecidas as características do veículo. Esta busca produzirá uma relação com os veículos que cumprem as características selecionadas.
    Após clicar na placa do veículo, clique na opção "Editar" na próxima tela, informe as alterações necessárias e clique em "Salvar".
