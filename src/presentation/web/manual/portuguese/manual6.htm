CONDUTORES
 
Esta função permite gerenciar os dados dos condutores.

 
Condutores/Gerenciamento
 
 
O item Gerenciamento permite ingressar, editar e excluir dados dos condutores, assim como ativar e desativar os dados de um condutor previamente cadastrado. Todos os campos sinalizados com * devem ser compulsoriamente preenchidos.
  • Para incluir um novo condutor clique em "Adicionar Condutor";.
  • Para modificar um condutor já cadastrado é preciso buscá-lo de forma simples ou avançada. O Data Center exibirá uma tela com os dados do condutor. Clique no nome do condutor e em seguida no botão Editar. Execute as alterações necessárias e clique no botão "Salvar".
  • Para excluir um condutor já cadastrado é preciso buscá-lo de forma simples ou avançada. O Data Center exibirá uma tela com os dados do condutor. Clique no nome do condutor e em seguida no botão Desativar. Preencha os campos com a data da exclusão e comentários (motivo da exclusão do funcionário) e clique no botão "Desativar".
 
 
Caso o usuário não disponha da data de nascimento do condutor, o mesmo deverá informar 1 de janeiro de 1925 no campo correspondente. Para data de admissão na companhia, informar 1 de janeiro de 1940, e para vencimento da C.N.H. informar 1 de janeiro de 2050.
