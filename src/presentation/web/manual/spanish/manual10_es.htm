Flotas/Mantenimiento de Flota
 
 
Permite crear, editar y borrar flotas generales o colectivas en el Data Center.
Flotas/ Ingreso Km/Millas y Eventos Colectivos
 
 
En esta pantalla es posible seleccionar la flota para la cual el usuario ingresará los datos colectivos o individuales referentes al kilometraje/millaje recorrido por los vehículos de la flota en un período determinado. Para ello alcanza con realizar una búsqueda.Esta función puede sustituir los datos enviados mensualmente a CEPA Data Center.
En este modulo también podremos ingresar los eventos reportados de forma colectiva ( eventos no reportados mediate formularios).

Descipción del proceso operacional para el ingreso de km/millas de forma colectiva:

  • Seleccionar el nombre de la flota (mediante la búsqueda);
  • Seleccionar el período para el cual el usuario reportará los datos;
  • Hacer click sobre el nombre de la flota;
  • Para cada División organizacional incluir el número de vehículos, millas/ kilómetros, accidentes e incidentes del período seleccionado anteriormente. Haga click sobre "Guardar".

Descipción del proceso operacional para el ingreso de eventos colectivos: En la misma pantalla de ingreso de km/millas colectivas completar más abajo los campos correspondientes a los datos de accidentes y incidentes: División, Clasificación, Cantidad, etc.

Descripción del proceso operacional para el ingreso de km/millas de forma individual:

  • Seleccionar el nombre de la flota (mediante la búsqueda);
  • Seleccionar el período para el cual el usuario reportará los datos;
  • Hacer click sobre el nombre de la flota;
  • Ingresar el odómetro actual, cantidad de accidentes e incidentes para cada vehículo.
