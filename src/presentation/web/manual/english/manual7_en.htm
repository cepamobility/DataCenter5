BASIC INSTRUCTIONS ON ACCESS AND USE
QUERIES
 
This element allows users to query and view a group of drivers that meet specific criteria.

 
Drivers/Queries/By Driver and Event
 
 
 
This item allows users to search for drivers following different selection criteria such as country, division, unit and number of recorded events. It also enables sorting and viewing drivers by number of fines, accidents and incidents.
 
Drivers/Queries/License Expiry Date
 
 
This item allows users to query and view a group of drivers sorted by organizational criteria and Driver’s License expiry date.
