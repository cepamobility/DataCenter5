This material should be used as quick reference. It contains a brief explanation of
the applications offered by the system to users.
 
 
Drivers
 
Management: Allows users to input, edit, delete, activate and deactivate driver data.
    
 
 
 
Queries/By Driver and Event: Allows users to search for drivers according to organizational criteria such as country, division, and unit as well as by number of recorded events.
    
 
Queries/License Expiry Date: Allows users to query and view a group of drivers according to an organizational structure as well as the expiry date of the driver’s license.
    
   
 
 
Events
   
Management: Allows users to input, edit and delete Events (Accidents, Incidents and Traffic Fines).
  
 
 
   
Queries/By Event: Displays a list of events containing date, name and surname of the driver, division, subdivision, unit, general classification and description of the event, and a link to the event report.
  
 
 
   
Queries/By Type: Displays a table with the number of accidents, incidents and fines classified according to company criteria. The table also indicates the main consequence of the accidents.
